# MojiKit 动作序列设计器 - PC端版本

## 📋 版本说明

**PC端版本**通过USB线直接连接Arduino Mega2560，使用Web Serial API实现浏览器与Arduino的直接通信。适合开发调试和近距离控制场景。

## 🔧 硬件要求

### 控制板
- **Arduino Mega2560** × 1

### 舵机系统
- **标准PWM舵机**（如SG90、MG996R等）× 16个
- **舵机电源**：外部5V电源，电流容量≥5A

### 连接线
- USB线（Arduino Mega2560与电脑连接）
- 舵机连接线（16根）

## 📐 硬件连接

### Arduino Mega2560引脚分配

| 结构代码 | 结构名称 | 舵机编号 | Arduino引脚 | 功能说明 |
|---------|---------|---------|------------|---------|
| RF | 右前脚 | 舵机1, 2 | D30, D31 | 抬起/放下、弯曲 |
| LF | 左前脚 | 舵机3, 4 | D32, D33 | 抬起/放下、弯曲 |
| RR | 右后脚 | 舵机5, 6 | D34, D35 | 抬起/放下、弯曲 |
| LR | 左后脚 | 舵机7, 8 | D36, D37 | 抬起/放下、弯曲 |
| TA | 尾巴 | 舵机9, 10 | D38, D39 | 左右摇摆、上下弯曲 |
| RE | 右耳 | 舵机11, 12 | D40, D41 | 旋转、俯仰 |
| LE | 左耳 | 舵机13, 14 | D42, D43 | 旋转、俯仰 |
| HD | 头部 | 舵机15, 16 | D44, D45 | 左右转动、上下点头 |

### 连接步骤

1. **舵机连接**
   - 将16个舵机按照引脚分配表连接到Arduino Mega2560
   - 舵机信号线（橙色/黄色）连接到对应数字引脚
   - 舵机电源正极（红色）连接到外部5V电源正极
   - 舵机电源负极（棕色/黑色）连接到外部5V电源负极和Arduino GND

2. **USB连接**
   - 使用USB线连接Arduino Mega2560到电脑USB端口

3. **电源连接**
   - 为舵机提供外部5V电源（建议使用5V/5A以上电源适配器）
   - 确保Arduino Mega2560通过USB或外部电源供电

## 🚀 软件设置

### 1. 上传Arduino程序

1. 打开Arduino IDE
2. 选择开发板：**Arduino Mega2560**
3. 选择正确的串口
4. 打开 `Arduino/USBcontrol0809.ino`
5. 点击"上传"按钮上传程序到Arduino

### 2. 运行前端界面

1. 使用**Chrome**或**Edge**浏览器（支持Web Serial API）
2. 打开 `index.html` 文件
3. 点击"🔌 连接Arduino"按钮
4. 在设备选择对话框中选择Arduino Mega2560
5. 连接成功后，状态显示将变为"已连接"

## 🎮 使用方法

### 基本操作流程

1. **选择结构**
   - 点击左侧结构按钮（RF、LF、RR、LR、TA、RE、LE、HD）
   - 选中的结构会高亮显示

2. **设置参数**
   - **前方角度(F)**：-90到+90度
     - 脚部：正值=抬起，负值=放下
     - 尾巴：正值=顺时针摇摆，负值=逆时针摇摆
     - 耳朵/头部：旋转角度
   - **弯曲角度(R)**：-90到+90度
     - 脚部：弯曲角度
     - 尾巴：上下弯曲角度
     - 耳朵/头部：俯仰角度
   - **速度等级(S)**：1-5（1最慢，5最快）
   - **执行前延迟**：0-10000ms

3. **添加动作**
   - 点击"➕ 添加动作"按钮
   - 动作会自动添加到时间轴

4. **编辑序列**
   - 拖拽动作块调整开始时间
   - 拖拽右侧边缘调整持续时间
   - 双击动作块编辑参数

5. **执行控制**
   - **▶️ 播放序列**：开始执行动作序列
   - **⏸️ 暂停**：暂停当前执行
   - **⏹️ 停止**：停止执行并复位
   - **🔄 复位**：所有舵机回到中位

## 📝 指令格式

### 新格式（推荐）
```
结构 F角度 R角度 S速度 D延迟
```

**示例：**
```
RF F30 R20 S3        # 右前脚：抬起30度，弯曲20度，速度3
LF F-30 R15 S2       # 左前脚：放下30度，弯曲15度，速度2
TA F45 R0 S4         # 尾巴：顺时针摇摆45度，速度4
RE F20 R-10 S3       # 右耳：旋转20度，俯仰-10度，速度3
HD F0 R15 S2         # 头部：左右0度，上下点头15度，速度2
```

### 多动作序列
```
RF F30 R20 S3;LF F-30 R15 S2;TA F45 R0 S4
```

### 带延迟的动作
```
RF F30 R20 S3 D1000;LF F-30 R15 S2
```

### 特殊指令
- `q` - 复位所有舵机到中位
- `s` - 查看系统状态

## 🔧 核心功能

### Arduino程序特性
- **8个结构控制**：支持8个结构独立控制
- **动作队列管理**：每个结构最多10个动作排队执行
- **平滑运动**：高级缓动函数，实现自然运动效果
- **并发执行**：多个结构同时执行动作，互不干扰
- **延迟支持**：动作执行前可设置延迟时间

### 前端界面特性
- **可视化编辑**：拖拽式时间轴编辑器
- **动作预览**：3D机器人模型实时预览
- **代码生成**：自动生成Arduino可执行的代码
- **实时通信**：Web Serial API直接连接Arduino
- **状态监控**：实时显示连接状态和执行进度

## 🔧 故障排除

### 无法连接Arduino
1. **检查浏览器**：确保使用Chrome或Edge浏览器（支持Web Serial API）
2. **检查USB连接**：确认USB线连接正常
3. **检查串口**：确认Arduino程序已上传，串口未被其他程序占用
4. **检查驱动**：确认Arduino驱动已正确安装

### 动作执行异常
1. **检查舵机连接**：确认所有舵机连接正确
2. **检查引脚配置**：确认引脚与代码配置一致
3. **检查电源供应**：确认舵机电源充足（建议≥5A）
4. **检查舵机型号**：确认使用标准PWM舵机

### 界面显示问题
1. **刷新页面**：按F5刷新页面
2. **清除缓存**：清除浏览器缓存
3. **检查控制台**：打开浏览器开发者工具查看错误信息

### 调试模式

启用调试模式查看详细信息：

```javascript
// 在浏览器控制台中启用调试
localStorage.setItem('debug', 'true');
location.reload();
```

## ⚠️ 注意事项

1. **电源要求**
   - 16个舵机同时工作需要足够的电流（建议≥5A）
   - 使用外部电源为舵机供电，不要仅依赖Arduino的5V输出

2. **浏览器兼容性**
   - 必须使用支持Web Serial API的浏览器
   - 推荐：Chrome 89+、Edge 89+

3. **安全提示**
   - Web Serial API需要用户授权才能访问串口
   - 首次连接时需要选择设备并授权

4. **性能建议**
   - 避免同时执行过多动作
   - 合理设置速度等级，过快可能导致舵机抖动
