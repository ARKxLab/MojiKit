# MojiKit 动作序列设计器 - ESP32 WiFi版本

## 📋 版本说明

**ESP32 WiFi版本**通过WiFi无线连接控制机器人，ESP32作为WiFi热点和指令转发器，实现远程控制。适合远程控制、演示展示和多设备控制场景。

## 🔧 硬件要求

### 控制板
- **Arduino Mega2560** × 1（主控制器）
- **ESP32开发板** × 1（WiFi通信模块）

### 舵机系统
- **标准PWM舵机**（如SG90、MG996R等）× 16个
- **舵机电源**：外部5V电源，电流容量≥5A

### 连接线
- USB线（Arduino Mega2560与电脑连接，用于上传程序）
- USB线（ESP32与电脑连接，用于上传程序）
- 舵机连接线（16根）
- 杜邦线（ESP32与Arduino连接）

## 📐 硬件连接

### Arduino Mega2560引脚分配

| 结构代码 | 结构名称 | 舵机编号 | Arduino引脚 | 功能说明 |
|---------|---------|---------|------------|---------|
| RF | 右前脚 | 舵机1, 2 | D30, D31 | 抬起/放下、弯曲 |
| LF | 左前脚 | 舵机3, 4 | D32, D33 | 抬起/放下、弯曲 |
| RR | 右后脚 | 舵机5, 6 | D34, D35 | 抬起/放下、弯曲 |
| LR | 左后脚 | 舵机7, 8 | D36, D37 | 抬起/放下、弯曲 |
| TA | 尾巴 | 舵机9, 10 | D38, D39 | 左右摇摆、上下弯曲 |
| RE | 右耳 | 舵机11, 12 | D40, D41 | 旋转、俯仰 |
| LE | 左耳 | 舵机13, 14 | D42, D43 | 旋转、俯仰 |
| HD | 头部 | 舵机15, 16 | D44, D45 | 左右转动、上下点头 |

### ESP32与Arduino Mega2560连接

| ESP32引脚 | Arduino Mega2560引脚 | 说明 |
|----------|---------------------|------|
| GPIO16 (RX) | TX1 (18) | ESP32接收Arduino数据 |
| GPIO17 (TX) | RX1 (19) | ESP32发送数据到Arduino |
| VIN | 5V | 电源正极（可选，ESP32可独立供电） |
| GND | GND | 电源负极（必须连接） |

### 连接步骤

1. **舵机连接**（与PC版本相同）
   - 将16个舵机按照引脚分配表连接到Arduino Mega2560
   - 舵机信号线连接到对应数字引脚
   - 舵机电源连接到外部5V电源

2. **ESP32与Arduino连接**
   - ESP32 GPIO16 → Arduino TX1 (18)
   - ESP32 GPIO17 → Arduino RX1 (19)
   - ESP32 GND → Arduino GND
   - ESP32 VIN → Arduino 5V（可选，ESP32可独立供电）

3. **电源连接**
   - 为舵机提供外部5V电源
   - Arduino Mega2560通过USB或外部电源供电
   - ESP32可通过Arduino的5V供电或独立供电

## 🚀 软件设置

### 1. 上传Arduino程序

1. 打开Arduino IDE
2. 选择开发板：**Arduino Mega2560**
3. 选择正确的串口
4. 打开 `Arduino/Arduino2560control.ino`
5. 点击"上传"按钮上传程序到Arduino

### 2. 上传ESP32程序

1. 在Arduino IDE中安装ESP32开发板支持
   - 文件 → 首选项 → 附加开发板管理器网址
   - 添加：`https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`
   - 工具 → 开发板 → 开发板管理器 → 搜索"ESP32"并安装

2. 选择开发板：**ESP32 Dev Module**

3. 打开 `ESP32/ESP32_WiFi_Server.ino`

4. 配置WiFi（可选，默认已配置）
   ```cpp
   const char* ssid = "RobotControl";        // WiFi热点名称
   const char* password = "12345678";        // WiFi密码
   ```

5. 点击"上传"按钮上传程序到ESP32

### 3. 连接WiFi并访问

1. **连接WiFi热点**
   - 在PC/手机/平板上搜索WiFi网络
   - 连接到名为 `RobotControl` 的WiFi热点
   - 输入密码：`12345678`

2. **访问网页界面**
   - 打开浏览器
   - 访问 `http://192.168.4.1`
   - 页面将显示机器人动作序列设计器

3. **连接ESP32**
   - 点击页面上的"📡 连接ESP32"按钮
   - 系统将自动检测ESP32连接状态
   - 连接成功后，状态显示将变为"已连接ESP32"

## 🎮 使用方法

### 基本操作流程

1. **选择结构**
   - 点击左侧结构按钮（RF、LF、RR、LR、TA、RE、LE、HD）

2. **设置参数**
   - **前方角度(F)**：-90到+90度
   - **弯曲角度(R)**：-90到+90度
   - **速度等级(S)**：1-5
   - **执行前延迟**：0-10000ms

3. **添加动作**
   - 点击"➕ 添加动作"按钮
   - 动作会自动添加到时间轴

4. **编辑序列**
   - 拖拽动作块调整时间
   - 双击动作块编辑参数

5. **执行控制**
   - **▶️ 播放序列**：开始执行动作序列
   - **⏸️ 暂停**：暂停当前执行
   - **⏹️ 停止**：停止执行并复位
   - **🔄 复位**：所有舵机回到中位

## 📝 指令格式

### 新格式（推荐）
```
结构 F角度 R角度 S速度 D延迟
```

**示例：**
```
RF F30 R20 S3        # 右前脚：抬起30度，弯曲20度，速度3
LF F-30 R15 S2       # 左前脚：放下30度，弯曲15度，速度2
TA F45 R0 S4         # 尾巴：顺时针摇摆45度，速度4
RE F20 R-10 S3       # 右耳：旋转20度，俯仰-10度，速度3
HD F0 R15 S2         # 头部：左右0度，上下点头15度，速度2
```

### 多动作序列
```
RF F30 R20 S3;LF F-30 R15 S2;TA F45 R0 S4
```

### 特殊指令
- `q` - 复位所有舵机到中位
- `s` - 查看系统状态

## 🔧 核心功能

### ESP32功能
- **WiFi热点**：创建WiFi热点供设备连接
- **Web服务器**：提供网页界面和API接口
- **指令转发**：将HTTP命令转发到Arduino串口
- **响应监控**：监控Arduino响应并返回给客户端

### Arduino程序特性
- **WiFi通信支持**：通过Serial1与ESP32通信（波特率115200）
- **8个结构控制**：支持8个结构独立控制
- **动作队列管理**：每个结构最多10个动作排队执行
- **平滑运动**：高级缓动函数，实现自然运动效果
- **并发执行**：多个结构同时执行动作

### 前端界面特性
- **可视化编辑**：拖拽式时间轴编辑器
- **动作预览**：3D机器人模型实时预览
- **WiFi连接管理**：自动检测和连接ESP32
- **实时通信**：通过WiFi实时发送命令和接收响应
- **状态监控**：实时显示连接状态和执行进度

## 🔧 故障排除

### 无法连接WiFi
1. **检查ESP32**：确认ESP32正常启动，查看串口监视器
2. **检查WiFi名称**：确认WiFi热点名称为 `RobotControl`
3. **检查密码**：确认密码为 `12345678`
4. **重启ESP32**：断开电源重新上电

### 无法访问网页
1. **检查WiFi连接**：确认已连接到ESP32的WiFi热点
2. **检查IP地址**：确认访问的IP地址正确（通常是 `192.168.4.1`）
   - 查看ESP32串口监视器确认实际IP地址
   - 详见 [Docs/IP地址说明.md](Docs/IP地址说明.md)
3. **尝试刷新**：按F5刷新页面
4. **检查防火墙**：确认防火墙未阻止连接

### 命令发送失败
1. **检查WiFi连接**：确认设备已连接到ESP32热点
2. **检查ESP32与Arduino连接**：确认串口连接正确
3. **检查串口配置**：确认波特率为115200
4. **查看ESP32串口输出**：查看是否有错误信息

### 连接状态异常
1. **重新连接**：点击断开连接后重新连接
2. **检查ESP32运行状态**：查看串口监视器
3. **重启ESP32**：断开电源重新上电

### 跨域访问问题（CORS）
如果遇到"Failed to fetch"或CORS错误：
1. 确保ESP32代码包含CORS头支持（代码已包含）
2. 重新上传ESP32固件
3. 检查浏览器控制台是否有CORS相关错误

## ⚠️ 注意事项

1. **IP地址**
   - ESP32的IP地址通常是 `192.168.4.1`（默认值）
   - 建议通过串口监视器确认实际IP地址
   - 详见 [Docs/IP地址说明.md](Docs/IP地址说明.md)

2. **WiFi配置**
   - 默认WiFi热点名称：`RobotControl`
   - 默认密码：`12345678`
   - 可在 `ESP32_WiFi_Server.ino` 中修改

3. **串口配置**
   - ESP32与Arduino通信波特率：115200
   - 确保ESP32和Arduino的串口配置一致

4. **电源要求**
   - 16个舵机同时工作需要足够的电流（建议≥5A）
   - ESP32可通过Arduino的5V供电或独立供电

5. **多设备连接**
   - 多个设备可以同时连接到ESP32热点
   - 所有设备都可以访问和控制机器人
