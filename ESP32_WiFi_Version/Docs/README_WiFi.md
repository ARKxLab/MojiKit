# WiFi控制系统使用说明

## 🎯 系统概述

本系统通过ESP32模块为Arduino Mega2560舵机控制系统提供WiFi通信功能，允许用户通过网页界面远程控制机器人。

## 🔧 硬件连接

### Arduino Mega2560 + ESP32连接
```
ESP32模块          Arduino Mega2560
TX (GPIO17)   →    RX1 (19)
RX (GPIO16)   →    TX1 (18)
VIN           →    5V
GND           →    GND
```

### 舵机连接
```
舵机1-16  →  D30-D45 (按顺序连接)
```

## 📋 文件说明

1. **Arduino/Arduino2560control.ino** - Arduino Mega2560主程序（已添加WiFi支持）
2. **ESP32/ESP32_WiFi_Server.ino** - ESP32 WiFi服务器程序
3. **Web/index.html** - ESP32服务器网页界面
4. **README_WiFi.md** - 本说明文档

## 🚀 使用步骤

### 1. 上传程序

#### Arduino Mega2560程序
1. 打开Arduino IDE
2. 选择开发板：Arduino Mega2560
3. 打开 `Arduino/Arduino2560control.ino` 文件
4. 上传程序到Arduino Mega2560

#### ESP32程序
1. 打开Arduino IDE
2. 选择开发板：ESP32 Dev Module
3. 打开 `ESP32/ESP32_WiFi_Server.ino` 文件
4. 修改WiFi配置（可选）：
   ```cpp
   const char* ssid = "RobotControl";        // WiFi热点名称
   const char* password = "12345678";        // WiFi密码
   ```
5. 上传程序到ESP32

### 2. 连接硬件

1. 按照硬件连接图连接ESP32和Arduino Mega2560
2. 连接所有舵机到对应的引脚
3. 为Arduino Mega2560供电

### 3. 启动系统

1. 上电后，ESP32会自动创建WiFi热点
2. 热点名称：`RobotControl`
3. 密码：`12345678`
4. 默认IP地址：`192.168.4.1`

### 4. 连接控制

1. 用手机或电脑连接WiFi热点 `RobotControl`
2. 密码：`12345678`
3. 打开浏览器，访问：`http://192.168.4.1`
4. 开始远程控制机器人！

## 🎮 控制界面

### 快速指令
- **复位** - 所有舵机回到中位
- **状态** - 查看当前系统状态
- **右前脚抬起** - 右前脚抬起30度
- **左前脚放下** - 左前脚放下30度
- **尾巴摇摆** - 尾巴摇摆20度
- **右耳转动** - 右耳转动15度

### 自定义指令

#### 新格式指令
```
RF F30 R20 S3    # 右前脚抬起30度，弯曲20度，速度3
LF F-30 R15 S3   # 左前脚放下30度，弯曲15度，速度3
TA F20 R10 S2    # 尾巴摇摆20度，弯曲10度，速度2
RE F15 R5 S3     # 右耳旋转15度，俯仰5度，速度3
HD F10 R-5 S3    # 头部左右转动10度，上下点头-5度，速度3
```

#### 旧格式指令
```
RFu40,-20,3      # 右前脚舵机1旋转40度，舵机2旋转-20度，速度3
LFu-30,15,3      # 左前脚舵机1旋转-30度，舵机2旋转15度，速度3
```

#### 多动作指令
```
RF F30 R20;LF F-30 R15;RR F25 R-10    # 同时控制多个结构
```

#### 特殊指令
```
q                # 复位所有舵机
s                # 查看系统状态
duration(RF F40 R20 S5;LF F-30 R15 S3)  # 计算指令执行时间
```

## 🔧 故障排除

### 常见问题

1. **编译错误：Servo库不兼容**
   - **问题**：ESP32不支持标准Servo库
   - **解决**：ESP32只负责WiFi通信，舵机控制由Arduino Mega2560负责
   - **注意**：不要将Arduino代码上传到ESP32

2. **ESP32Servo库错误**
   - **问题**：ESP32Servo库依赖问题
   - **解决**：ESP32只需要运行WiFi服务器程序，不需要舵机控制
   - **注意**：ESP32只使用 `ESP32/ESP32_WiFi_Server.ino` 文件，不控制舵机

3. **无法连接WiFi热点**
   - 检查ESP32是否正常启动
   - 确认WiFi热点名称和密码
   - 重启ESP32

4. **指令无响应**
   - 检查ESP32和Arduino的连接
   - 确认串口波特率设置（115200）
   - 检查Arduino程序是否正常运行

5. **舵机不动作**
   - 检查舵机电源连接
   - 确认舵机引脚连接正确
   - 检查Arduino程序中的引脚定义

6. **网页无法访问**
   - 确认已连接到正确的WiFi热点
   - 检查IP地址是否正确
   - 重启ESP32

7. **字符编码错误**
   - **问题**：HTML中包含无效字符
   - **解决**：已修复ESP32代码中的字符问题
   - **注意**：使用最新版本的 `ESP32/ESP32_WiFi_Server.ino`

### 调试方法

1. **查看串口输出**
   - Arduino Mega2560：连接USB查看Serial输出
   - ESP32：连接USB查看Serial输出

2. **检查网络连接**
   - 确认WiFi热点已创建
   - 检查设备是否已连接
   - 测试网络连通性

3. **测试通信**
   - 通过串口发送测试指令
   - 检查ESP32和Arduino之间的通信
   - 验证WiFi指令转发功能

## 📝 注意事项

1. **电源要求**
   - Arduino Mega2560需要稳定的5V电源
   - 舵机需要足够的电流供应
   - 建议使用外部电源适配器

2. **网络安全**
   - 默认WiFi密码较简单，建议修改
   - 仅在内网环境使用
   - 不要连接到公共网络

3. **系统稳定性**
   - 避免频繁发送指令
   - 定期检查系统状态
   - 及时处理错误信息

4. **兼容性**
   - Arduino代码仅适用于Arduino Mega2560
   - ESP32代码仅适用于ESP32开发板
   - 不要混淆两个程序
   - ESP32只负责WiFi通信，不控制舵机
